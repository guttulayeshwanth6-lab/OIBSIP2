# Number Guessing Game – Java

## Project Overview
The Number Guessing Game is a simple Java-based console application developed as Task 2 during my Java Development Internship at OASIS INFOBYTE.

In this game, the computer generates a random number, and the user tries to guess it within a limited number of attempts. The game provides hints to help the user guess the correct number.

## Features
- Generates a random number.
- Allows the user to enter guesses.
- Displays hints such as **Too High** or **Too Low**.
- Limits the number of attempts.
- Displays the result when the user wins or runs out of attempts.
- Provides an interactive console-based gaming experience.

## Technologies Used
- **Programming Language:** Java
- **JDK:** Java Development Kit (JDK 21)
- **IDE:** Visual Studio Code
- **Input Handling:** Scanner class
- **Random Number Generation:** Random class

## How to Run the Project

1. Install JDK on your computer.
2. Open the project folder in Visual Studio Code.
3. Open the Java source file.
4. Open the terminal in VS Code.
5. Compile the Java file:

   ```bash
   javac NumberGuessingGame.java
   ```

6. Run the program:

   ```bash
   java NumberGuessingGame
   ```

   Replace `NumberGuessingGame` with your actual Java class name if it is different.
